🚀 GET STARTED IN 30 SECONDS!

================================================================================
STEP 1: START SERVER
================================================================================

Open terminal and run:

    cd /data3/megan_data/Jimmy/Volume_Prediction
    python src/web/sam_website.py

Server starts at: http://127.0.0.1:5015

================================================================================
STEP 2: OPEN WEB INTERFACE
================================================================================

Open browser and navigate to:

    http://127.0.0.1:5015

You'll see the SAM Interactive Segmentation interface.

================================================================================
STEP 3: UPLOAD IMAGE
================================================================================

Click "Browse Files" or drag & drop an image.

Result: 
   ✅ Image displayed
   ✅ NEW "Pre-Segmentation Filter" panel appears!

================================================================================
STEP 4: APPLY PRE-FILTER (OPTIONAL)
================================================================================

The new panel has these controls:

   Brightness:      [slider]  -100 to +100  (default: 0)
   Contrast:        [slider]   0.5 to 3.0   (default: 1.0)
   Filter Mode:     [dropdown] 4 options    (default: No Filtering)
   Min Threshold:   [slider]   0 to 255     (conditional)
   Max Threshold:   [slider]   0 to 255     (conditional)

Quick Examples:

   A) Remove Dark Background:
      - Filter Mode: "Remove Dark Pixels (Below Threshold)"
      - Min Threshold: 50
      - Click "Apply Filter"

   B) Brighten Image:
      - Brightness: +30
      - Contrast: 1.2
      - Click "Apply Filter"

   C) Keep Specific Range:
      - Filter Mode: "Keep Only Range"
      - Min: 60, Max: 180
      - Click "Apply Filter"

================================================================================
STEP 5: RUN SAM SEGMENTATION
================================================================================

After filtering (or skip filtering):

   1. Configure SAM parameters (Model Size, Points per Side, etc.)
   2. Click "🎯 Run SAM Segmentation"
   3. Wait 30-60 seconds
   4. View results!

================================================================================
STEP 6: ITERATE (OPTIONAL)
================================================================================

Not happy with results?

   1. Click "Reset" in Pre-Filter panel
   2. Try different filter settings
   3. Apply and run SAM again

================================================================================
WHAT IF SOMETHING GOES WRONG?
================================================================================

Issue: Panel doesn't appear
   → Make sure image uploaded successfully (check green checkmark)

Issue: Filter has no effect
   → Check your threshold values aren't too extreme
   → Try clicking "Reset" and start over

Issue: Image turns black
   → Thresholds too strict! Click "Reset"
   → Use more lenient values (wider range)

Issue: Can't run SAM
   → Make sure SAM configuration is set
   → Check that "Run SAM Segmentation" button is enabled
