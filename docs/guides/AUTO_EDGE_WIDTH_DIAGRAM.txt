ALGORITHM FLOW:
──────────────

1. Select Target Droplet
   └─> Mask ID = 5

2. Find All Other Droplets
   └─> Create combined mask of masks 0,1,2,3,4,6,7,8...

3. Calculate Distance Transform
   └─> For each pixel, compute distance to nearest other droplet
   
       Distance Map Example:
       ....5555555555....
       ..55555555555555..
       .5555555555555555.
       555555 [O] 555555   ← Numbers show distance in pixels
       .5555555555555555.
       ..55555555555555..
       ....5555555555....

4. Sample Along Contour
   └─> Check distance at each contour point of target droplet
   
       Contour Point → Distance Check
       ──────────────────────────────
       Point 1       → 45 pixels
       Point 2       → 50 pixels
       Point 3       → 12 pixels  ← Minimum distance!
       Point 4       → 30 pixels
       ...

5. Calculate Optimal Width
   └─> Optimal = min(12 - 2, 100) = 10 pixels
       (Subtract 2px safety margin, cap at max 100px)

6. Use Optimal Width
   └─> Dark edge detection now uses 10px width instead of default


BENEFITS:
─────────

✓ Prevents false positives from neighboring droplets
✓ Adaptive per droplet (crowded areas get smaller width)
✓ Maintains accuracy of dark ring measurements
✓ Safe with built-in margin
✓ Backward compatible (opt-in feature)

TECHNICAL SPECIFICATIONS:
─────────────────────────

Distance Calculation:
  - Method: OpenCV distanceTransform()
  - Type: L2 (Euclidean distance)
  - Mask Size: 5 (for accuracy)

Edge Width Constraints:
  - Minimum: 5 pixels
  - Maximum: 100 pixels
  - Safety Margin: 2 pixels

Performance:
  - Caching: Yes (keyed by mask_id, edge_width, darkness_threshold)
  - Computation: O(n) where n = contour points (typically fast)
  - Distance Transform: O(w*h) where w,h = image dimensions (one-time)
