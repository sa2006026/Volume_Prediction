================================================================================
FILTER MODES EXPLAINED
================================================================================

Mode 1: "No Pixel Filtering"
   → Only applies brightness/contrast adjustments
   → No pixels removed

Mode 2: "Remove Dark Pixels (Below Threshold)"
   → Shows: Min Threshold slider
   → Removes all pixels with intensity < min_threshold
   → Use case: Remove dark background, shadows, noise

Mode 3: "Remove Bright Pixels (Above Threshold)"
   → Shows: Max Threshold slider
   → Removes all pixels with intensity > max_threshold
   → Use case: Remove overexposure, bright artifacts, glare

Mode 4: "Keep Only Range (Between Thresholds)"
   → Shows: Both Min and Max Threshold sliders
   → Keeps only pixels with min <= intensity <= max
   → Removes everything outside this range
   → Use case: Isolate specific intensity band

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Issue: Panel doesn't appear after upload
   → Check browser console for JavaScript errors
   → Verify upload was successful (check network tab)
   → Try refreshing the page

Issue: Filter button does nothing
   → Check if image is actually loaded
   → Verify server is running (check status message)
   → Look for error messages in browser console

Issue: Image turns completely black
   → Thresholds are too restrictive
   → Click "Reset" button
   → Use less aggressive threshold values

Issue: Sliders don't show for filter mode
   → This is correct! Some modes don't use all sliders
   → "No Filtering" → no threshold sliders
   → "Remove Dark" → only min slider
   → "Remove Bright" → only max slider
   → "Keep Range" → both sliders

Issue: Filter applied but SAM results unchanged
   → Make sure you applied filter BEFORE running SAM
   → If SAM already ran, run it again after filtering
   → Check that filtered image actually changed
