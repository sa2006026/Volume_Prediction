╔══════════════════════════════════════════════════════════════════════════════╗
║                          QUICK START GUIDE                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝

1️⃣  Upload your image

2️⃣  In SAM Configuration:
    • Enable "Overlap Filter" checkbox
    • Set threshold (e.g., 0.80 for 80% overlap)
    • Choose removal mode:
      → "Larger mask" if you want precise, smaller masks
      → "Smaller mask" if larger masks are more accurate

3️⃣  Click "Run SAM Segmentation"

4️⃣  Review results

5️⃣  (Optional) Re-apply with different settings:
    • Open "Overlap Filter" panel
    • Change threshold or removal mode
    • Click "Apply Overlap Filter"

╔══════════════════════════════════════════════════════════════════════════════╗
║                            TIPS & TRICKS                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

💡 Start with default settings (0.80 threshold, remove larger)
💡 Use the Overlap Filter Panel to experiment without re-running full segmentation
💡 Higher threshold = more strict (only removes very overlapping masks)
💡 Lower threshold = more aggressive (removes masks with less overlap)
💡 Check the "Overlap Filter Results" message to see how many masks were removed
💡 Use "Reset Filter" to restore all masks and try different settings
