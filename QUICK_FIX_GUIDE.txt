╚══════════════════════════════════════════════════════════════════════════════╝

PROBLEM:
  After applying intensity filter, ALL bounding boxes still show
  instead of only showing boxes for masks inside the range.

ROOT CAUSE:
  Frontend not updating its mask list when filter response arrives.

THE FIX (ONE LINE):
  
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ In your applyIntensityFilter() function, add this line:                   │
  │                                                                            │
  │   currentMasks = response.masks;  ← THIS UPDATES THE MASK LIST            │
  │                                                                            │
  └────────────────────────────────────────────────────────────────────────────┘

BEFORE (WRONG):
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ let allMasks = [];  // Set once during segmentation                       │
  │                                                                            │
  │ async function applyIntensityFilter(min, max) {                           │
  │     const response = await fetch('/apply_intensity_filter', {...});      │
  │     const data = await response.json();                                   │
  │                                                                            │
  │     // ❌ MISSING: allMasks = data.masks;                                 │
  │     redrawBoundingBoxes();  // Still uses old allMasks with 45 items!     │
  │ }                                                                          │
  └────────────────────────────────────────────────────────────────────────────┘

AFTER (CORRECT):
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ let currentMasks = [];  // Single source of truth                         │
  │                                                                            │
  │ async function applyIntensityFilter(min, max) {                           │
  │     const response = await fetch('/apply_intensity_filter', {            │
  │         method: 'POST',                                                   │
  │         headers: {'Content-Type': 'application/json'},                    │
  │         body: JSON.stringify({                                            │
  │             min_intensity: parseInt(min),                                 │
  │             max_intensity: parseInt(max)                                  │
  │         })                                                                │
  │     });                                                                   │
  │                                                                            │
  │     const data = await response.json();                                   │
  │                                                                            │
  │     if (data.success && data.masks) {                                     │
  │         currentMasks = data.masks;  // ✅ UPDATE THE MASK LIST!           │
  │         redrawBoundingBoxes();      // ✅ Now uses filtered list!         │
  │     }                                                                      │
  │ }                                                                          │
  └────────────────────────────────────────────────────────────────────────────┘

COMMON MISTAKES:
  ❌ Using multiple mask arrays (originalMasks, filteredMasks, etc.)
     ✅ Use ONE array: currentMasks
  
  ❌ Forgetting to update currentMasks from response
     ✅ Always: currentMasks = response.masks;
  
  ❌ Variable shadowing (let currentMasks = ... inside function)
     ✅ No 'let' when updating existing variable
  
  ❌ Drawing from wrong array (still using originalMasks)
     ✅ redrawBoundingBoxes() must use currentMasks

KEY PRINCIPLE:
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ Backend tells frontend EXACTLY what to display via the masks array.       │
  │ Frontend should TRUST and USE that array, not maintain its own filtering. │
  │                                                                            │
  │ Upload       → masks: []          → Clear all                             │
  │ Segmentation → masks: [45 items]  → Draw 45 boxes                         │
  │ Filter       → masks: [20 items]  → Draw 20 boxes                         │
  │ Reset        → masks: [45 items]  → Draw 45 boxes                         │
  └────────────────────────────────────────────────────────────────────────────┘

THAT'S IT! Just make sure your frontend updates currentMasks from the response.
