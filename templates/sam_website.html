Circularity Filter Results:
About Circularity:

Circularity = 4π × Area / Perimeter². Perfect circles have circularity = 1.0. Lower values indicate more elongated or irregular shapes. Use this to filter out non-circular objects.

About Dark Edge Detection:

This filter analyzes pixels around each mask's contour. Dark pixels (below threshold) are identified. The dark ratio = (dark pixels) / (total edge pixels). Use this to remove masks with dark boundaries. Enable "Show Dark Edges" to see blue-highlighted dark pixels in the preview.
